The Infinite Loop!

If a while loop condition NEVER becomes False, the loop will run forever!

INFINITE EXECUTION VISUALIZER:
Count: -1245...
Terminal Frozen! The condition stays True infinitely!

Why is this code trapped?

i = 1
while i <= 10:
    print(i)
    i = i - 1  # Bug! Decreasing instead of increasing!
Root Cause: Since i starts at 1 and keeps decreasing (0, -1, -2...), i <= 10 stays True forever! To fix it, ensure your variable moves TOWARDS making the condition False!
